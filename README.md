# Lingcoo 公共 Packages

这里维护跨多个 Lingcoo 应用复用的、边界稳定的基础能力。

公共包不属于 `ts-app-starter`。Starter 保持纯净，只提供运行环境、工程结构和交付基线；业务应用按需安装这里发布的包。

## 开发准则

- 优先使用 Node.js、PostgreSQL 和成熟开源依赖；
- 非必要不接入 SaaS 平台，避免额外账号、配置和运行时绑定；
- 公共包保持框架无关，不依赖具体业务数据库；
- 只抽取已经在多个项目中验证过的稳定能力；
- 不把用户模型、登录流程、RBAC、租户或行业业务做成公共包。

## 当前包

- `@lingcoo/security`：密码哈希、JWT、Bearer Token 和认证主体基础能力。
